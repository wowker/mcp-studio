# M2 配置与浏览器会话工程合同

日期：2026-10-13。授权仅 T10–T14；不实现 T15、M3 Tool / Tab / Run。依据设计基线 D01–D15、交付 02 / 04 / 05 和任务完成标准。

平台合同增加到兼容版本 1.1.0（既有 M1 操作不变）。配置、环境、变量有独立 ID、单调版本、强 ETag。PATCH / DELETE 必须 If-Match，缺失 428、不同 409；权限先于版本判断。平台以真实项目维护者身份允许公共内容写入；开发者和查看者可读；目录管理权不授予项目内容权。连接权限入口只核验项目 / 连接 / 配置版本 / 环境并返回当前身份，不代理 MCP 请求。

环境 base 以空 environmentId 表示，公共定义按项目 / 环境 / 可选连接分层；四层合并完成后再解析引用。敏感定义公共 valueJSON 必须为空，个人值仅浏览器内存。非敏感 valueJSON 是 JSON 编码值，0 / false / null 的存在不与缺失混淆。共同 M0 向量继续逐项验证两个独立生产解析器；参考 oracle 不进入生产。

公共 HTTP 配置只允许 http/https、非敏感查询、无 userinfo 和 fragment；识别到认证 query、原始认证 Header、可识别 token 时拒绝。查询引用的派生敏感性按真实配置作用域检查，不能凭名称认定所有业务值安全。stdio 固定 Agent，程序与参数数组分开，工作目录明确；M2 只保存配置，Agent 执行留在 M5。

被连接 / 定义引用的环境，以及仍有服务级定义的连接删除返回 object_in_use，需明确修复，不级联抹除层或自动退回 base。删除变量保留使用方表达式，使缺失来源可见。配置版本冲突保留本地草稿并提供远端比较；不隐式重试覆盖。

浏览器个人凭据按实际用户 + 项目 + 连接 ID 隔离，敏感变量按用户 + 项目 + 定义 ID 隔离。URL 相同不合并。退出 / 到期 / 权限失效清除个人值与连接。保存、选择环境、个人授权、握手是分离动作，任何修复均不自动连接。

浏览器 MCP 使用锁定 SDK 的明确 HTTP transport，不自动尝试另一个 transport 或 Agent。连接前核验平台权限及当前版本。浏览器直接访问目标资源，凭据不发给平台，不携带平台 Cookie；停止 / 迟到结果必须受会话代际保护。

OAuth 是公共客户端授权码 + PKCE S256，绑定 resource、scope、issuer、redirect URI 和单次 state；pending verifier 与 token 均只在当前浏览器内存。回调立即移除 URL 查询，严格校验 opener/source/origin，一次完成后拒绝重放。受限 discovery / token / CORS / 本机网络路径提供显式 Agent 配置入口，不绕过浏览器限制。受控本机 HTTP OAuth 仅测试开发例外，生产授权端点要求 HTTPS。

平台 CSP 允许 connect-src http: / https: 以实现用户选择的浏览器直连；不放宽 script-src、frame-ancestors 或基于同源的身份 API。浏览器对跨站 MCP/OAuth 请求使用 omit credentials。

T02 待验的目标浏览器、OS、本地网络授权及真实远端网络矩阵继续待验。M2 局部受控 SDK / 浏览器证据不得替代完整支持声明。C05 含 T15，当前阶段只记录 T13–T14 验证，不整体签署。

OAuth 当前可用协议范围是预注册的公共客户端，不执行动态客户端注册或自动刷新；授权服务器元数据与端点必须符合严格 HTTPS、同 issuer origin 的受支持范围。授权弹窗端点不能与平台使用同一主机名（不同端口亦禁止），因为弹窗导航不能设置 fetch 的 credentials: omit，平台 Cookie 不按端口隔离。OAuth 凭据绑定解析后的资源地址，修改地址必须重新授权。测试授权服务器使用 localhost、平台使用127.0.0.1，TLS证书只在隔离fixture中忽略错误。

配置URL可引用path/query公共变量，authority模板不在当前支持范围；先静态检查，再在实际四层作用域检查敏感派生及解析后的可识别秘密。复杂JSON或过多叶子无法可靠屏蔽时，服务器信息整块隐藏。SDK断流/onerror立即使会话失败并关闭，旧SSE不自动重试GET；断开、重连必须由用户动作触发。

凭据TTL过期、更换、移除按用户/项目/连接发送无秘密失效通知并断开已有SDK会话，包括未显示的服务页；个人值不继续留在已复制的transport Header中。退出/撤权与所有异步写操作使用身份代际栅栏，迟到保存/删除不能修改新账号草稿或导航。
