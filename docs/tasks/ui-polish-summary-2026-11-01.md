## 三、视觉体系变化

### 主色（紫 → 青绿）

| Token | 亮色 | 暗色 |
| --- | --- | --- |
| `--ui-accent` | `#267565` | `#85cfb5` |
| `--ui-accent-strong` | `#1c5a4d` | `#9adcc5` |
| `--ui-accent-muted` | `#e8f2ee` | `#2f4a3b` |
| `--ui-accent-border` | `#cfe3da` | — |

暗色 `accent-muted` 由 `#293f34` 调亮到 `#2f4a3b`：原值与 `surface-muted` 仅差 6 个十六进制步进，侧栏当前项与默认项肉眼无差别。

### 新增语义 token

`--ui-info`、`--ui-focus`、`--ui-danger-border`、`--ui-table-head`、`--ui-code-bg/text`、`--ui-shadow-panel`、`--ui-font-sans`、`--ui-font-mono`。`app.css` 约 40 处硬编码十六进制全部换成语义 token。

### 文字层级（浅色）

| Token | 调整前 | 调整后 | 语义 |
| --- | --- | --- | --- |
| `--ui-text-muted` | `#6a746f` | `#65706a` | 次级信息文本，AA 必须 ≥4.5 |
| `--ui-text-subtle` | `#8f9a94` | `#66706b` | 仅装饰/豁免层（禁用态、占位符、图标、边框） |

在 token 定义处新增注释固化该边界，防止后续把 subtle 调浅误伤信息文本；同时把 3 处错配的承载信息文本（空态提示、运行 ID、表单约束提示）归位到 muted（值不变、零视觉变化）。

### 布局密度

- Tool 目录默认宽度 300 → 236（拖拽区间 204–320，键盘步进同步），行高 40 → 32
- Servers 表格行高 11px 内边距 / 0.8rem 字号，操作列 `width: 1%` + `nowrap`
- 连接弹窗改 header + 可滚动表单网格，底部操作条 sticky
- 弹窗内四组视觉块：基础字段 / 认证 / Headers / 固定传输方式

### 响应式

| 断点 | 覆盖内容 |
| --- | --- |
| ≤1000px | 表格横向滚动（min-width 560px）、侧栏 192→156px、工具目录 180–220px |
| ≤640px | 弹窗全宽、表单单列、弹窗分组收紧、表 min-width 480px、侧栏收起 |

两段媒体查询集中追加在 `redesign.css` 末尾，不散落修改既有 `@media`。

## 五、过程中发现并解决的非预期问题

| 问题 | 根因 | 处理 |
| --- | --- | --- |
| `App.test.tsx` 偶发超时 | jsdom + Vite transform 链慢，5s lazy 超时不足 | 提升到 15s |
| e2e 断言已裁剪功能 | i18n-smoke 仍断言自动化测试/测试套件/测试报告导航 | 删除 3 行断言 |

| 视觉快照过时 | 文字色微调 | `--update-snapshots` 重拍 4 张 |
| Bearer Token 选择器歧义 | `/Bearer Token/` 同时匹配输入框与「显示」按钮 | 改用 `getByRole("textbox", …)` |
| 浅色回归出现 2.07 / 1.57 瞬时值 | 导航切换过渡动画中途取色 | 延长稳定等待后复测，确认非真实违规 |

## 七、限制与未覆盖

- 浏览器核对使用临时数据目录（`/tmp/mcp-ui-data`）与本地 fixture Server，**未覆盖真实远程 MCP 与 OAuth 回调路径**。
- 响应式只做了断点样式，**无真机/多设备验证**；≤640px 仅保证不回归。
- 以下区域未逐页打样：已保存请求、Tool 定义、脚本、Tab 右键菜单、JSON 全屏完整流程、空项目欢迎页（仅代码实现 + 单测覆盖）。
- e2e 新增断言的**负向验证未执行**（回退 token 观察断言失败）被安全策略拦截；该结论由浏览器实测数据间接支撑（旧值 2.91/4.38 确实低于 4.5）。
- 截图取证在部分时段不可用（浏览器标签页节流），改用计算样式取值作为证据。
