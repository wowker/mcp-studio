## 每批执行协议

1. **预期核对**：从 06 验收清单取条目正式预期文本与行号，登记批次 JSON。
2. **证据生产**：
   - 两版项 = 云版证据（真实 PG + 真实邮件夹具 + 浏览器）**和**单机版证据（`apps/local` 形态，回环；涉多项目场景显式断言项目归属过滤仍生效，方法论 R3）。
   - 仅云版项 = 云版证据。
   - 触及领域（E03/E04/E05/E08/E06/E10）不引用 V01 旧证据。
3. **只读审阅**：无 Critical/Important；Minor 登记。
4. **逐条签收**：满足方法论第 4 节五条标准后，CSV 状态「待验收」→「已签收」，逐条进行；证据落 `tests/evidence/acceptance-<批次>/`。
5. **批次出口**：progress.md 登记本批修改、实际验证、限制、签收数；环境受限子项显式保留待验。

## 通用限制（全程有效）

- 环境受限项（T02 矩阵、T32b 人工、签名与公证、三 OS 凭据库、内嵌 PG 三 OS 首启）缺环境保持待验，不阻断同批其他条目推进，但所属条目不签收。
