# 管理页面统一设计

状态：可点击的设计原型，尚未进入正式开发。沿用已经选定的灰白 / 青绿工作台、左侧导航、右上角用户、底部语言与亮暗主题。本轮只修改 `docs/redesign/`，不接入真实账号、邮件、MCP、数据库或 Go 服务。

## 页面与布局

| 页面 | 组织方式 | 主要操作 |
| --- | --- | --- |
| 服务配置 | 左侧连接列表；右侧固定连接标题、配置导航、滚动表单与底部保存 | 基础信息、认证引用、自定义请求头；切换到执行与存储 |
| 环境变量 | 左侧环境列表；右侧环境身份、作用域导航和变量表 | 生效预览、项目变量、服务变量；进入完整变量编辑页 |
| 调用历史 | 整页列表；已保存作为第二分类；独立调用详情页 | 搜索、状态 / 服务筛选、参数和响应、固定、保存、载入新调试页 |
| 团队成员 | 成员 / 邀请分类；统一角色与状态表格 | 查看成员权限、创建示例邀请、撤销示例邀请 |
| 邀请成员 | 页内邮箱和角色表单；右侧权限预览；固定底部操作 | 团队角色、初始项目、项目角色；必填邮箱校验 |
| 变量编辑 | 页内名称、类型、作用域和值；右侧环境与服务上下文 | 普通值、JSON、敏感值标记；类型错误提示、保存 / 取消 |

标题统一为 20px，说明为 12px，表格和辅助说明为 11–12px；页面内边距统一为 24px，窄屏为 16px。主要输入高度 36px，表单最大宽度 720px。表头采用次级表面色，状态标签收紧为 4px 圆角。延续现有语义 tokens 与 Phosphor 图标，不引入另一套设计系统。

服务配置、环境变量共享同样的主从布局和局部导航层级。服务配置的连接身份和导航固定，表单独立滚动，保存操作留在底部。执行与存储页面也使用同一个页面标题组件。

项目总历史取消挤占宽度的旁侧摘要，点击记录直接进入完整详情页。搜索和筛选保留；返回时沿用先前条件。详情仍展示只读参数、响应、执行身份和协议，并能载入新的未执行草稿。工具调试内的调用历史继续限定于当前项目、连接与工具，不跳转到总历史。

邀请表单进入独立页面，团队角色和项目角色分别设置，右侧说明随选择更新。原型只创建内存记录；示例到期日期按原型日期 2026-10-12 加七天展示。撤销保留现有二次确认，避免误触。正式邀请权限、邮件和接受流程仍需后续单独设计与实现。

## 状态与交互规则

- 中英文仅显示当前语言；用户配置名称、邮箱、工具名称、参数类型和服务原始数据保留原值。
- 主题、语言及配置视图切换保留编辑草稿。草稿按项目隔离；变量编辑保留原环境和服务 ID，不因顶部切换调试连接而改写归属。
- 邀请邮箱使用原生必填与邮箱格式校验。变量名称和类型错误显示在表单内，并关联到对应输入框；语言切换后错误重新翻译。
- 编辑基础环境变量时仍保存到原基础环境，不改成当前预览环境。数值 `0`、布尔值 `false` 都是有效值。
- 已有敏感值不填入编辑器；替换输入使用密码框。原型不持久化敏感值，业务数据和草稿不进入浏览器偏好存储。
- 只读角色下邀请页字段和提交禁用。所有权限状态为演示，不能代替服务端授权。
- 窄屏将左侧连接 / 环境列表改为横向列表，表单和权限预览纵向排列；底部操作保持可见。宽表仅在表格容器内横向滚动，页面本身不产生横向溢出。历史列表独立纵向滚动，末尾记录可以访问。
- 工具参数的默认跳过规则不变：新草稿非必填项默认跳过，恢复的明确参数保持原值。

## 组件复用

`workbench-components.js` 新增 `pageHeading` 与 `sectionHeading`，供服务配置、执行设置、环境、总历史、已保存集合、团队和页内编辑使用。管理页面样式集中在 `workbench-management.css`；邀请与变量编辑草稿由独立 `workbench-management.js` 演示模块管理。

正式组件边界与单独管理方式更新在 [COMPONENTS.md](./COMPONENTS.md)。这些是设计契约，字符串模板和内存模拟不作为正式前端实现直接复用。

## 本轮验证

- `node docs/redesign/verify-management-model.mjs`：10 组设计模型回归通过，覆盖语言资源、邀请草稿、项目隔离、取消、变量归属、敏感值、错误关联、只读与文本转义。
- `node docs/redesign/verify-execution-model.mjs`：9 组原有执行设置模型检查通过，覆盖 stdio / 浏览器约束、备份默认值、命令校验和连接隔离。
- 通过 Codex 浏览器实际检查页面导航、邀请创建 / 撤销、必填邮箱、角色预览、语言 / 主题草稿保留、变量错误提示与 `0` 保存、连接配置草稿、历史筛选返回及工具历史范围。
- 1440px 中文亮色页面、1024px 英文暗色四页面，以及 390px 服务、环境、历史和邀请布局已检查。390px 历史列表内容高 713px、可视高 535px，允许内部纵向滚动；表格宽 720px、容器宽 260px，横向滚动限定在表格容器。英文邀请页无页面横向溢出。
- 检查到的当前预览 Tab 错误日志为空。模型与浏览器检查只证明原型的设计交互；本轮未运行正式 `npm run verify`，未验证真实授权、持久化、邮件或 MCP 调用。
