## 当前阶段：工程入口与参数组件

目标：交付可编译、可测试、可独立启动的 Go 平台服务和 React / TypeScript 工作台，将参数编辑器从字符串原型转成受控组件。该阶段为开发工程基础，不作为可部署的完整团队平台。

目录：`service-workbench/platform` 为独立 Go module；`service-workbench/web` 为 Vite / React 入口。复用根工程已安装的前端依赖、共享 JSON Schema 校验、Schema 字段模型和 primitives，不替换现有应用入口、不连接原有 SQLite 数据。

- [x] 修正原型：新草稿可选项默认跳过；取消跳过 / 聚焦不显示错误；真实编辑和执行再校验；恢复与复制保留原参数。
- [ ] Go 平台：标准库 HTTP 入口，健康检查、独立静态前端分发、错误 JSON、优雅退出和请求超时；无私有数据和模拟登录。
- [ ] React 标准 `SchemaArgumentEditor`：受控草稿、字段类型、可选省略、延迟错误、Form / Raw、复杂 JSON 草稿、显式校验、身份隔离。
- [ ] 工作台 Shell：沿用已确认布局，折叠导航、顶部用户、底部语言 / 主题；未接入登录和项目时显示真实空态。

验收：所有新可选字段默认不进入 payload；Schema default 仅在明确启用时使用；仅聚焦不能制造错误或改变参数；校验失败不得提交；`0 / false / null / [] / {}` 按 Schema 处理；无非法原文丢失、跨 Tab 污染或业务数据浏览器持久化。
