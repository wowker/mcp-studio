## 已统一的行为

- 固定是项目级保留操作，仅 Maintainer 可操作；Developer / Viewer 均不可固定。上传重试同时要求本人、有效项目访问和可执行角色，其他成员的队列按钮禁用。
- 平台离线或容量满时，新的调用明确停止；已发出的调用可结束并排队。会话到期时页面遮蔽、上传暂停。
- 模拟浏览器刷新后，原浏览器调用显示“结果未知”，不假装可恢复执行；Agent 调用可以继续。公共电脑仅内存模式显式展示丢失结果。
- 列表每页 50 条。90 天普通历史清理保护固定记录、已保存记录和待上传队列。
- 中英文标题只显示一种语言；原有低于 11px 的文字提升到下限，正文调整到 14px，新页面沿用现有表单与页面间距。
- 页面内完成确认与修订，不引入调试 / 历史弹出框。新页面保留滚动位置；入口资源版本已更新，避免旧浏览器缓存显示过期交互。

## 原型边界

所有业务状态仍只存在内存中。所谓持久化、恢复、容量、初始化、邮件、认证、Agent 安装 / 配对和审计都属于设计情景；**真正刷新浏览器会重置示例状态**。仅界面语言和主题沿用现有偏好保存。

队列页面上的“模拟刷新恢复”专门演示目标体验，不证明 IndexedDB、系统凭据库、平台托管加密、可靠上传或真实跨设备恢复已经实现。移除后私有记录封存 30 天、凭据备份删除和备份介质淘汰以页内说明表达，真实生命周期任务留给后续工程。

高级 Schema 使用已有本地预览校验器，未抓取远程 Schema。Endpoint 的示例检测覆盖敏感字段名和变量来源；这不是正式秘密检测或安全防护实现。正式实现继续执行 08 的已确认规则，不能直接复用静态原型的内存模拟作为安全边界。
