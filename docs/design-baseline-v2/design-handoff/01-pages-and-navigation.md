# 01 · 页面结构与导航

[交付首页](./README.md) · [下一篇：核心流程](./02-core-flows.md)

## 信息架构

```text
工作台 Shell
├─ 侧栏：品牌 / 项目选择 / 服务 / 工具 / 环境变量 / 调用历史
│        项目与成员入口 / 收起 / 主题 / 语言（最下方）
├─ 顶栏：当前服务、环境、个人授权来源、连接状态 / 用户（右上角）
└─ 主工作区
   ├─ 项目管理 → 创建项目 → 新项目起始页 / 项目流程
   ├─ 服务 → 连接配置 / 授权与凭据 / 本机 Agent
   ├─ 环境变量 → 生效预览 / 项目定义 / 服务定义 / 引用检查
   │            → 来源详情 / 变量编辑 / 个人敏感值 / 备份
   ├─ 工具 → 目录 → 文档 Tab
   │       ├─ 调试：参数 / 执行结果
   │       ├─ 定义
   │       ├─ 此工具调用历史 → 详情 → 恢复 / 保存
   │       └─ 此工具已保存 → 详情 / 保存页
   ├─ 项目调用历史 / 已保存 → 详情 → 恢复 / 编辑元数据
   └─ 成员与邀请 → 项目成员 / 团队成员 / 邀请记录 / 权限说明
                → 成员详情 / 创建邀请 / 邀请详情 / 接受邀请
```

顶栏描述真实工作上下文。平台用户身份、连接的 MCP 授权来源和执行设备是不同概念；不使用含糊的“项目服务账号”让用户误以为所有成员共用一个登录身份。

## 页面清单

下面是**原型定位参数**，不是正式前端路由或 API 合同。所有入口以 `workbench-preview.html?` 开始；`project=commerce` 是稳定示例，`knowledge` 为另一示例项目。本次会话创建的临时 ID 刷新后失效。

| 页面 / 原型定位 | 结构与主要动作 | 返回与上下文 |
| --- | --- | --- |
| 项目目录 `page=projects` | 搜索、项目列表、当前标记、成员 / 服务数量、创建、打开 | 选择项目后进入对应工作区，不启动调用 |
| 创建项目 `page=project-editor` | 名称、描述、校验、保存 / 取消 | 保留来源上下文；成功进入空项目 |
| 新项目起始页 `page=project-welcome` | 配置首个服务、管理成员 | 不填充电商示例数据 |
| 项目流程 `page=project-flow` | 7 步进度、下一步、继续操作 | 进度来自实际原型状态，不提供“伪完成”开关 |
| 服务 `page=servers&config=connection` | 左列表、右连接表单、诊断、保存 / 连接 | `server` 指定连接对象 |
| 授权 `page=servers&config=authorization` | 授权方式、个人凭据、保存位置、个人备份 | 返回同一连接配置或工具，不共享同 URL 授权 |
| Agent `page=servers&config=execution` | 配对来源、设备、能力、在线状态、配对 / 解除 | 配对完成后仍需连接 MCP |
| 环境 `page=environment` | 环境导航、局部视图、变量表、来源详情、应用会话 | 浏览环境不改变运行环境 |
| 变量编辑 `page=variable-editor` | 名称、类型、作用域、必需、值、保存 / 取消 | 从所属环境 / 连接进入；草稿在内存 |
| 调试 `page=tools&tab=tab-11&view=debug` | 目录、文档 Tab、参数、结果 | 默认视图，当前连接内保留多个草稿 |
| 工具定义 `page=tools&view=definition` | 描述、输入 / 输出 Schema、原始定义 | 返回同一 Tab |
| 工具历史 `page=tools&view=history` | 限定此工具的筛选及列表 | 绝不跳到项目总历史 |
| 工具历史详情 `page=tools&view=history-detail&run=…` | 请求 / 响应、上下文、脱敏、恢复、保存 | 返回同一工具历史及筛选位置 |
| 工具已保存 `page=tools&view=saved` | 当前工具记录、可见范围、内容类型 | 详情 `view=saved-detail&record=…` |
| 工具保存页 `page=tools&view=save-record` | 名称、备注、范围、冻结快照 | 必须从有来源的动作进入 |
| 项目历史 `page=history&collection=calls` | 项目内跨服务 / 工具筛选、排序、分页 | 总历史与工具历史独立筛选 |
| 项目已保存 `page=history&collection=saved` | 私有 / 项目范围、仅请求 / 带响应、上传状态 | 仅展示有权访问记录 |
| 历史详情 `page=history-detail&run=…` | 只读执行快照、脱敏、上传状态、恢复 | 返回来源列表，保留筛选和页码 |
| 保存详情 `page=saved-detail&record=…` | 快照、元数据、来源执行、编辑 / 删除 / 恢复 | 来源历史不存在时保存快照仍可读 |
| 保存编辑 `page=record-editor` | 元数据、范围、请求 / 响应预览 | 新保存冻结来源；修改元数据不改快照 |
| 成员 `page=members&section=projectMembers` | 项目成员列表与角色筛选 | `teamMembers` 为团队成员 |
| 邀请列表 `page=members&section=invitations` | 邮箱、状态、角色、到期时间 | `permissions` 为权限说明 |
| 成员详情 `page=member-detail&entry=…` | 团队角色、本项目角色、所属项目、移除确认 | 保留列表上下文 |
| 创建邀请 `page=invitation` | 邮箱、团队角色、指定项目、项目角色、期限 | 权限摘要与提交在页面内 |
| 邀请详情 `page=invitation-detail&entry=team-invite-1` | 生命周期、重发 / 撤销 | `mode=accept` 为受邀者模拟视角 |
| 身份流程 `page=login` | 登录、邀请邮箱验证 / 设置账号、找回 / 重设密码、一次性 Owner 初始化 | 从账号入口或邀请修复动作进入对应子状态；验证后返回原邀请，不自动接受；SSO 不在首版 |
| 账号与会话 `page=account` | 当前身份、会话到期、退出前待上传处理 | 平台身份与 MCP 授权分开；角色下拉仅为原型预览 |
| 项目访问 `page=access` | 项目成员关系、Owner 接管原因 / 页内确认、管理记录 | Admin 无自行接管；接管其他项目不改变当前项目角色 |
| 记录与设备 `page=operations` | 本人当前项目责任端队列、上传重试、保留方式、离线 / 容量说明 | 重试不调用工具；不能显示或操作他人本地队列 |

`view`、编辑来源、详情筛选及局部表单由原型内存管理；不要把任意拼接 URL 当作完整编辑流程。正式深链接、返回地址、失效链接规范需另定。

## 修补后统一的页面衔接

- 服务诊断“检查环境变量”进入该连接的生效环境及引用检查，保留未保存输入；补齐后重新计算错误，不继续显示旧的缺失提示。修复不自动连接。
- 授权引用选择器只提供当前项目 / 服务 / 环境可用定义范围内的敏感变量。已选引用失效时仍显示其名称与缺失原因，不能替换为其他项目的预设值。
- 邀请身份修复返回相同邀请，重新检查状态；到期、撤销、被替代均不可接受。
- 会话到期遮蔽项目内容；无项目访问权时不显示服务上下文和项目流程进度。Owner / Admin 的目录及成员管理例外不开放内容；普通成员不得凭旧维护者状态进入管理页。
- 已保存详情、名称修订、来源调用与恢复入口保持记录身份；恢复的新 Tab 状态为未执行。

完整页面索引、交互索引和验收入口见 [11 最终交付清单](./11-final-delivery-checklist.md)。

## 工具工作区层级

1. **工具目录**属于当前连接：名称搜索、全部 / 收藏 / 最近 / 变化 / 移除等状态筛选。长名称省略并可查看完整值。
2. **文档 Tab**是独立草稿：同一工具可以打开多个 Tab。右侧菜单作用于其目标 Tab，不能误改当前 Tab。
3. **工具局部视图**是调试 / 定义 / 历史 / 已保存等页面，不新增全局弹窗。
4. **参数编辑模式**是表单 / 原始 JSON；复杂字段内还可选择结构 / JSON。两层切换都必须保持同一草稿语义。
5. **结果页签**只切换本次 Run 的展示：请求与结果、调用详情、HTTP、RPC、时间线。stdio 不伪造 HTTP 记录。

工具 Tab 菜单：复制名称、复制 Tab、固定 / 取消固定、左移、右移、关闭其他、关闭右侧。固定项在本连接前部，移动限于各自固定分组；运行或固定项不被批量关闭。复制生成新 Tab ID，只复制参数和编辑模式，不复制运行中或成功状态。

## 导航与隔离

| 切换 | 保留 | 不能发生 |
| --- | --- | --- |
| 语言 / 主题 | 所有草稿、运行状态、筛选、当前上下文滚动位置 | 触发保存、执行、授权或跳转 |
| 收起侧栏 | 页面与草稿，核心导航可访问 | 内容被裁切、无法重新展开 |
| 项目 | 各项目各自的角色能力、会话草稿及列表状态 | 沿用前项目角色；把旧项目迟到结果写入新项目；复制私人凭据 |
| 连接 | 各连接 Tab、授权与变量边界 | 按 URL 合并授权或服务级变量 |
| 工具 Tab | 独立参数、结果、局部视图 | 新工具覆盖旧草稿或借用其 Run |
| 详情返回列表 | 来源筛选、排序、页码 | 回到无关的总历史 |
| 历史恢复 | 原记录只读、新个人草稿 | 自动执行；显示旧响应为新成功 |

操作中离开页面的处理须区分业务类型：失效的页面回调不得更新新页面；已经发出的 MCP 调用或服务端写入不能因前端离开就宣称已撤销。正式实现需结合操作 ID 查询权威结果。

## 布局与空态

桌面采用固定 Shell、独立内容滚动。管理页统一为标题 / 局部导航 / 内容 / 操作尾部；主从页面左侧选对象、右侧编辑。窄屏目录或服务列表变为横向可滚动区域，主表单与说明纵向排列。

空项目、无服务、无工具、无历史、无保存记录分别提供创建或前往调试入口；搜索无结果只提供清除筛选。无权限与对象不存在有各自页面，不能用空列表伪装。具体状态见 [04](./04-states-and-data.md)。

## Baseline 2 · 补充界面

D01–D15 已确认，以下规则已有静态页面或示例状态承载，入口映射见 [09](./09-baseline-v2-prototype-sync.md)：

| 区域 | 已确认的页面 / 状态要求 |
| --- | --- |
| 账号 | 一次性 Owner 初始化、邀请注册、邮箱验证、密码登录 / 找回、退出前待上传提示；关闭公开注册 |
| 项目管理 | Owner 显式接管的页内确认与审计说明；Admin 未加入项目不可读内容 |
| 已保存 | 私有“未完成请求草稿”标记；Schema 错误可保留，禁止发布 / 执行 |
| 服务 / Agent | 非敏感 query 配置、安装 / 首次配对、执行配置变化确认、个人备份恢复 |
| 工作台状态 | 平台离线阻止新调用、持久化脱敏队列、容量不足、响应截断、角色撤销 |
| 记录管理 | 维护者固定、本人队列重试、上传后追加脱敏修订、保留期说明 |
| 共享编辑 | 配置版本冲突，保留本地草稿并提供比较入口 |

`account` 承载账号入口，`login` 承载身份流程，`access` 承载项目接管，`operations` 承载设备队列与容量；其他状态整合进现有领域页，均为设计模拟。
