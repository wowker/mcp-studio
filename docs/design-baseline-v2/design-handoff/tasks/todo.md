# 实施任务与检查点

日期：2026-10-13。状态：全部未开始。依据 [实施计划](./plan.md)；本表仅安排后续独立目录开发。

36 个 T 编号是工作包；每包进一步分为 a / b 两个顺序执行的切片，共 72 个叶子任务。每个切片目标为 S–M（约 1–5 个文件，含测试），表中路径仅表示未来责任范围。开工时在既定范围内补登记准确文件；若单个切片仍超过 5 个文件或一次专注工作可验证的规模，继续拆分并保留父编号，不把整个工作包一次性实现。这里不承诺工时。

依赖栏列工作包前置；默认 b 依赖 a。验收列是各叶子任务的完成标准；验证列是后续必须建立 / 运行的检查，不代表现在已有命令或已通过。共同门禁见 plan 第 6 节；测试和证据纳入同一切片。所有最终 A 项状态仍为待验收。
