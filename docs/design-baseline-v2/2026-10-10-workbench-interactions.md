# 工作台二次设计：工具历史、Tab 菜单与外观

日期：2026-10-10。状态：可操作的设计预览，调用为模拟；Go 后端与正式 TypeScript + React 客户端尚未开发。本文补充并更新前一版布局文档中的入口位置与历史行为。

## 布局

保持左侧导航、工具目录、多工具 Tab 与上参数 / 下结果的结构。将用户信息固定在右上角；左下角依次为团队成员、主题按钮和语言选择，语言位于最下方。侧栏支持手动切换 192px 展开与 80px 图标模式；窄窗口自动使用图标模式。项目在展开侧栏和底部状态栏显示，收起后可通过项目按钮切换。

顶部连接栏只负责当前服务、环境、凭据归属与连接操作，用户信息置于栏右侧。工具 Tab 一行、工具标题一行、调试 / 定义 / 当前工具历史 / 已保存一行，分别承担文档管理、执行与页面导航的职责。

认证标识改为“认证：项目凭据” / “认证：我的授权” / “认证：无需凭据”。点击后进入活动连接的认证配置并定位到认证区域，显示与工作台登录账号的区别。详细调用位置与凭据边界见 [本地优先执行架构](./2026-10-10-local-first-mcp-architecture.md)。

新增平台调用历史与已保存请求 / 响应的流程，见[记录功能设计](./2026-10-10-platform-history-and-saved-records.md)。

## 当前工具历史

调试栏的“调用历史”打开当前工具工作区内的列表页面，与最左侧“调用历史”模块分开。查询范围精确为当前项目、连接 ID 和工具名称；工具历史和总历史的筛选各自保存。不同 Tab 保留各自的工具历史筛选。

列表显示状态、Run ID / 参数字段数、调用人、耗时和时间，支持按调用 ID / 调用人搜索及状态筛选。详情在同一工作区中查看请求快照、结果和协议信息；可以返回列表或打开调试。恢复参数始终创建新个人 Tab，不自动执行，不覆盖当前草稿。

原型路由示例：

```text
?page=tools&project=commerce&tab=tab-11&view=history
?page=tools&project=commerce&tab=tab-11&view=history-detail&run=commerce-run-01
```

详情支持浏览器前进 / 后退和直接链接；不属于当前工具、连接或项目的 Run 显示不可用。执行快捷键只在调试视图有效。

## 每个工具 Tab 的右侧操作

| 操作 | 行为 |
| --- | --- |
| 复制名称 | 复制该 Tab 的 Tool 名，不改变当前 Tab |
| 复制 Tab | 新建独立参数草稿，保留原文、Form / JSON 模式及非法输入；不复制执行结果 |
| 固定 / 取消固定 | 固定 Tab 前置，关闭按钮禁用；取消固定后可关闭 |
| 左移 / 右移 | 在同一连接、同一固定分组中调整位置，到边缘时禁用 |
| 关闭其他 | 保留目标 Tab，同时保护固定和运行中的 Tab |
| 关闭右侧 | 只关闭目标右侧可关闭的 Tab，保护固定和运行中的 Tab |

菜单放在每个 Tab 名称右侧、关闭按钮之前。对非当前 Tab 操作不会误用当前 Tab 的参数。菜单支持键盘方向键、Home / End、Escape 和 Tab；固定项有图钉及选中状态，禁用动作保留文字。

## 双语与亮暗主题

默认简体中文与亮色，支持 `zh-CN` / `en-US` 和 `light` / `dark`。每次只显示所选语言的标题与说明；服务原始内容、工具名和参数名保持原值。亮暗主题共享布局和语义 tokens，覆盖输入框、列表、菜单、弹层、错误和成功状态。

主题与侧栏切换直接调整外观，保留未保存的配置、参数、光标和编辑器 DOM。语言切换保留草稿、调用状态和页面。原型仅把 locale 与 theme 的枚举值保存为偏好；不保存身份、凭据、参数或响应。

## 组件与验证

账户入口、外观设置、工具 Tab、Tab 菜单、历史表格已拆入独立预览模块；历史表格在总历史与工具历史中共用。调试布局、Schema 编辑、结果与快照的正式组件边界见 [标准组件契约](./COMPONENTS.md)。

```sh
node docs/redesign/verify-preview.mjs
node docs/redesign/verify-preview-locales.mjs
node docs/redesign/verify-workbench-controls.mjs
```

原型检查覆盖既有交互、双语、工具历史范围、菜单目标身份、执行 / 固定保护、外观切换与 1440 / 1024 / 820 / 390px 布局。它不验证正式 Go 服务、真实 MCP / OAuth、用户登录、租户授权或 Secret 持久化。
