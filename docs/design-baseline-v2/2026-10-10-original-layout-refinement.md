# 原布局内美化与页面式调试

日期：2026-10-10。状态：按用户最新选择调整的设计预览；未实现 Go 后端或替换现有产品代码。

后续更新：用户已提供现有 UI 截图，布局明确为左侧功能导航、工具目录及上下调试区。最新主布局以[截图参考二次设计](./2026-10-10-reference-ui-redesign.md)为准；本文的页面式历史和草稿边界继续有效。

## 已确定的方向

用户选择最初的布局版本，在布局内进行 UI 美化；调试窗口和调用历史尽可能使用页面，不用弹框承载主要工作流程。第二轮 A / B / C 方案保留作为参考，不再作为主布局建议。

主预览：[workbench-preview.html](./workbench-preview.html)。仍保留顶部四个业务导航、团队 / 项目入口、Server / 环境上下文、左侧 Tool 目录、个人多 Tab、参数 / 结果分栏及底部状态栏。Server、环境变量和团队体系沿用第一轮功能范围。

## 美化内容

- 使用浅灰蓝背景、白色工作面与低饱和蓝色强调，明确区分导航、上下文和编辑区域。
- 顶部导航采用紧凑选择状态；Tool 目录增加分组间距、圆角选中态与层次。
- 保留 Tab 位置，优化当前 Tab、关闭按钮和新增草稿的表现。
- 调试标题补充草稿归属、Schema 校验和输入字段数；主要执行动作仍固定在原位置。
- 参数 / 结果仍并排，使用独立工作面、固定页头 / 页脚和可调分栏；没有普通面板阴影或渐变。
- 结构化商品数组展示为只读表格，并保留原始 JSON 与调用详情。其他响应保持 JSON 展示；正式版本的内容查看器按第二轮专项规划逐步实现。
- Server、环境变量与历史页面同步采用相同 tokens、边框和控件样式，不增加第二套设计系统。

## 页面边界

| 功能 | 交互方式 |
| --- | --- |
| Tools 调试 | 完整工作台页面；多个独立个人 Tab，保留草稿 |
| 工具定义 | 当前工作区内的定义页面；返回调试保留参数，不打开弹窗 |
| Tool 的历史入口 | 跳转调用历史页，按当前 Tool / connection ID 筛选 |
| 调用历史 | 原列表与右侧概览布局；点击记录进入完整详情页 |
| 调用详情 | 页面级上下文、只读请求与结果、协议与执行身份；返回历史保留筛选 |
| 恢复参数 | 新建个人调试 Tab，标记来源 Run；不自动执行 |
| 复制受限 | 切换到原始 JSON 视图供手动复制，不再用弹框承载结果 |
| 简短配置编辑与确认 | 新增变量、邀请成员、撤销 / 清理确认仍可使用弹框 |

预览页面以 `page`、`project`、`tab`、`run`、`view` 表达页面身份，支持浏览器前进 / 后退与示例记录的直接链接。URL 不包含参数、搜索关键词、变量值或凭据。示例状态只在内存中存在；刷新后恢复初始数据，临时新 Run 无法在刷新后继续读取。正式版由持久化 API 加载并检查用户权限。

## 重点调试行为

1. 参数与 JSON 模式共用输入，非法 JSON 保留且阻止执行。
2. 模拟执行固定参数和环境快照；执行中继续编辑时，结果明确标记为上次调用。
3. 查看定义、查看历史、返回工作台不丢失同一 Tab 草稿。
4. 只读历史详情不可编辑；恢复进入新的 Tab，不用历史结果冒充本次成功。
5. 同 URL 的连接仍按 connection ID 隔离；跨项目 Run 链接不自动寻找或加载其他项目记录。

正式版仍由 Go MCP 执行器发起调用，前端为 TypeScript + React。复杂 Schema、权威状态、SSE、取消语义、凭据和团队权限继续采用[Tools 专项规划](./2026-10-10-tools-workspace-design.md)的功能要求；其中布局推荐以本文更新为准。
