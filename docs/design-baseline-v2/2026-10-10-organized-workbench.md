# 调试工作台：重新整理布局

日期：2026-10-10。状态：交互设计原型，调用仍为模拟。

后续更新：[工具历史、Tab 操作与外观](./2026-10-10-workbench-interactions.md)。用户入口已移到右上角，语言位于左下方最底部，补齐亮暗主题、可收起导航与当前工具专属历史；下方保留本轮布局演进记录。

用户反馈前版不够美观且布局混乱。本轮重新组织工作区，沿用已确认的四模块范围、中英文切换、项目 / 连接 / Tab / Run 隔离、上下调试区及页面式历史。后端 Go 与前端 TypeScript + React 的正式实现范围不变。

## 信息位置

| 区域 | 负责的信息 |
| --- | --- |
| 左侧导航 | 品牌、团队 / 项目选择、四个模块、团队成员、语言、用户 |
| 顶部连接栏 | 服务选择、生效环境、凭据归属、连接状态与连接操作 |
| 工具目录 | 搜索、分类、工具选择；移除重复的服务与快照页脚 |
| 文档页签 | 已打开的个人工具草稿、新建、关闭 |
| 工具标题区 | 工具名、原始描述、执行 / 取消操作 |
| 工具视图导航 | 调试、工具定义、调用历史，独占一行 |
| 调试主体 | 参数编辑在上，结果在下；拖拽与键盘调整 |

前版把文档页签与局部导航放在同一行，且项目说明、部署标记、凭据和角色分散在多个顶栏。本轮收敛为单一连接栏，把项目切换移至侧边栏，移除重复状态和说明。主要执行按钮稳定放在工具标题右侧；参数切换与格式化放在参数区域，结果视图放在结果区域。

## 视觉与组件

- 中性灰白底色、白色工作面、低饱和青绿色强调；状态色仍独立表达成功、警告和失败。
- 工具目录使用灰色底面，工作区使用单一带细边界的白色表面；不添加阴影、渐变或嵌套卡片。
- 文档页签、页面导航、参数编辑模式、结果视图分别使用对应结构，避免多个相似选中态挤在同一行。
- 标题、描述、字段、表格采用不同字号与文字权重，减少标签和装饰图标。
- 移除参数区底部重复的校验提示，把空间留给输入与 Schema；调用快照身份仍保留在结果页脚。
- 用户区域语言选择采用完整宽度，两种语言不会挤压选择框。

## 其他页面

服务、环境、历史和成员页面共享同一导航与连接栏。配置采用列表与编辑页，历史采用列表 / 概览及完整详情页。工具定义为工作区内页面，能力信息和输入结构并列，窄窗口上下排列。主要调试与历史流程不使用弹框。

## 保留的交互与验证

不改变表单 / JSON 同步、非法草稿保护、数组输入校验、执行快照、取消、历史恢复、浏览器路由、同 URL 独立连接、权限演示和语言偏好。窄窗口下导航缩为图标，保留语言入口；目录转为搜索与横向工具选择，参数 / 结果顺序滚动。

```sh

node docs/redesign/verify-preview-locales.mjs
```
