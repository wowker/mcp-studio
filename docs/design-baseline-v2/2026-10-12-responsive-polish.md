# 双语、主题与窗口尺寸布局复核

仅调整 `docs/redesign/` 原型；保留已有布局、流程和示例数据逻辑。

## 已修复

- 统一状态容器不再覆盖子页面的高度计算，修复页面底部及操作栏被裁切。
- 环境详情、历史列表等网格使用可收缩列，避免英文标签撑宽整页。
- 窄屏历史筛选改为单列；分页和排序控件可换行，表格保留独立横向滚动。
- 页面标题、工具栏、操作按钮统一间距、换行与图标尺寸；长项目名、记录 ID 和说明可安全换行。
- 窄屏调试结果栏将状态与操作分行，防止状态按字拆行或保存/复制按钮被挤出。
- 短桌面窗口可滚动调试分区，保留参数和结果的最小可操作高度。
- 保存记录编辑页适配新的原型容器，恢复一致的页边距与边框。
- 表格支持键盘聚焦和横向滚动，焦点环使用现有主题 token。
- 同一页面上下文中，语言切换保留表格、目录、页签、定义页和移动调试区的滚动位置。项目/服务/工具/记录切换不会复用不相干页面的滚动位置。
- 底部状态栏固定单行，长项目名省略显示并提供完整名称提示。

新增样式集中在 `workbench-layout.css`，继续使用已有 tokens、系统字体、Phosphor 图标和按钮组件。中文、英文使用相同组件；主题由同一套语义 token 控制。

## 验证范围

15 个页面/视图 × 4 个窗口 × 2 种语言 × 2 种主题，共 240 组浏览器布局检查：

- 页面：项目列表/创建、团队成员/邀请/接受详情、服务连接/授权/Agent、环境变量、工具调试/定义、调用历史/已保存列表、调用详情、项目流程。
- 窗口：390×900、820×900、1024×640、1440×900；另外用 390×844 检查移动调试结果操作和键盘滚动。
- 自动几何检查：无页面横向溢出；页面底边在容器内；异步/内容滚动区不为零高度；主操作未被不可滚动的父容器横向裁切。可横向滚动的表格、目录、页签按预期保留横向滚动，不视为页面溢出。
- 人工截图核对英文亮色历史筛选/环境、英文暗色工具页、中文暗色移动工具结果栏及长项目名。
- 表格键盘横向滚动可达；语言切换前后表格位置 (80, 883) 保持一致，移动调试区纵向位置 629 保持一致。
- 原有 169 项设计模型检查通过；本轮不代表生产实现验证，未运行生产 build 或 npm run verify。

报告：`preview-assets/layout-browser-verification.json`。截图：`layout-tools-mobile-dark.png`、`layout-workbench-light.png`。

工具提供的名称、描述、参数和返回内容保留原始语言，不作为界面翻译缺失处理。此轮检查验证上述页面和尺寸，不声称覆盖所有操作状态的视觉组合。
