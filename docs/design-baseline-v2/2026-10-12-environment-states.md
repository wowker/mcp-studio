# 环境变量完整交互原型

日期：2026-10-12。范围：`docs/redesign` 内可交互原型与设计说明。没有进入正式开发，没有真实 MCP、凭据库、平台存储或备份请求。刷新页面会重置变量与业务状态；只持久化既有语言和主题偏好。

入口：[环境变量](./workbench-preview.html?page=environment&project=commerce)。沿用左侧环境列表、右侧工作区、中英文单语言界面、亮暗主题和可折叠侧栏。

## 页面与状态

| 区域 | 交互与状态 |
| --- | --- |
| 环境列表 | 基础、开发、预发；区分预览环境与当前会话；浏览不会应用 |
| 生效预览 | 每个名称一行；显示合并后的值、来源、敏感标记；名称搜索、缺失 / 敏感 / 覆盖筛选和空状态 |
| 项目 / 服务变量 | 查看当前环境及继承的基础定义；编辑保留原环境和连接；创建覆盖仅影响选定环境 |
| 页内来源详情 | 按优先级列出四层候选，标明生效 / 覆盖 / 未定义；提供编辑、创建覆盖、删除确认与回退 |
| 变量编辑页 | 名称、作用域、string / number / boolean / JSON、值、必需标记；敏感值只使用示例；保存 / 取消与字段错误 |
| 检查引用 | 显示授权、请求头、stdio 启动配置、变量相互引用的使用位置；定位并修复；缺失定义可直接新建 |
| 敏感值详情 | 脱敏、查看 / 隐藏示例、个人值更换、移除确认、本机 / 会话位置；个人备份默认关闭 |
| 个人备份 | 开启确认 → 进行中 → 成功 / 失败；失败保留本地值，可重试；更换值使旧备份过期；移除本地值后可确认恢复；删除备份单独确认 |
| 脱敏快照 | 页内只读 JSON；敏感变量及间接引用敏感值的变量均省略值，仅展示引用与状态 |

业务操作都在页面内完成。保留既有账号、项目切换等全局原型控件。

## 覆盖规则

沿用原设计中“项目与服务分别继承，服务变量优先”的规则：

**基础项目 < 当前环境项目 < 基础服务 < 当前环境服务。**

基础环境只包含两个基础层。同名变量在生效预览中只出现一次；项目 / 服务定义页保留各层定义，用于管理继承关系。变量绑定项目和服务 ID，不能按 URL 共用；相同 URL 的不同服务不互相取得服务级变量。

例：REGION 的四个候选分别为 `cn-east-1`、`ap-southeast-1`、`cn-north-1`、`cn-east-2`，最终使用 `cn-east-2`。删除最后一层定义后回退到 `cn-north-1`。`REGION_LABEL=region-{{REGION}}` 随最终值更新。

**保留定义但缺少值，不等于删除定义。** 高优先级敏感值未配置时必须报错，不偷偷使用低优先级值。

## 输入与缺失校验

- 只在保存时校验名称和类型，不因聚焦空输入而报错；错误关联字段，聚焦首个无效字段。
- 同一项目、环境、作用域及服务内不能有重名定义。不同环境 / 作用域允许同名，用于覆盖。
- 数字 `0`、布尔 `false` 为有效值。数字必须有限；布尔只接受 JSON `true` / `false`；JSON 支持对象、数组与原生 JSON 值。
- 普通可选变量允许空字符串；标记必需或作为服务直接必需引用时，空字符串 / 空白 / null 都显示缺失。
- 支持字符串和嵌套 JSON 的 `{{NAME}}` 引用；只解析生效定义的依赖，不让已被覆盖的旧引用造成误报。
- 缺失定义、个人敏感值缺失、必需空值、依赖缺失、循环引用分别显示。缺失名称本身进入检查列表，可直接创建。
- 授权引用的缺失变量默认新建为必需敏感变量；不提供真实 Token 输入框。
- 直接或间接依赖敏感值的派生变量整体脱敏，快照不能通过字符串拼接或嵌套 JSON 绕过脱敏。

## 会话与权限

- “用于我的会话”只影响当前用户的当前服务。已连接或连接进行中时禁用；存在未保存服务配置或环境问题时给出页内说明。
- 应用成功同时更新顶部会话环境和服务模型中的配置快照；不自动连接。浏览环境不修改会话。
- 连接前和工具执行前使用同一套环境检查。缺失项阻止新的模拟执行，已有历史快照保持不变；取消或环境编辑不代表远端回滚。
- 维护者可编辑共享定义。开发者可管理自己的敏感值，个人值编辑页锁定名称、类型、作用域和必需标记；查看者不允许修改或查看示例值。
- 草稿按项目、服务、预览环境隔离；切换语言、主题保留草稿。个人敏感值状态按用户 + 项目 + 变量 ID 隔离；项目级变量在项目内复用，服务级变量由其定义限定服务。
- 本机保存 / 恢复需要示例 Agent 已配对；也可选择仅当前会话。原型从不保存真实敏感字符串。
- 页面路由仍为环境页；局部筛选、详情、编辑草稿仅在内存保留，不把变量值写入 URL。

## 标准组件

复用现有 tokens、Phosphor 图标、按钮、表单、标题和主从布局。新增设计单元为 EnvironmentNavigator、VariableTable、ResolutionChain、VariableEditor、EnvironmentValidation、PersonalSecretPanel，契约见 [COMPONENTS.md](./COMPONENTS.md)。

`workbench-environments.js` 是可丢弃的内存设计模型，不是正式环境解析器或前端工程架构。未来正式开发需结合 Go 后端与本地 Agent 实现凭据库、跨用户权限、持久化、真实上传重试和运行快照；本轮仅用模拟数据验证页面逻辑。
