## 本轮补齐：执行与存储

服务配置新增“连接配置 / 执行与存储”两个页内入口。新视图分三个区段，用原生单选、输入、选择框和复选框，复用工作台 tokens 与 Phosphor 图标。

| 区段 | 可评审内容 |
| --- | --- |
| 调用从哪里发出 | HTTP / stdio，浏览器直连 / 本机 Agent，执行路径预览；stdio 禁止选择浏览器直连 |
| 设备 | 未配对、模拟配对、离线；配对说明在当前页面展开 |
| stdio 配置 | 命令、字符串数组参数、工作目录；校验不启动进程 |
| 授权与凭据 | 浏览器仅当前会话；Agent 可选择会话或本机凭据库；平台个人备份默认关闭 |
| 调用记录 | 平台保存请求参数、响应和耗时；凭据备份开关不影响历史；失败仅重传记录 |

已连接时需断开再调整设置。个人执行设置按项目和连接隔离；普通连接配置也在切换视图、连接及语言时保留内存草稿。Viewer 仅查看，Developer 可编辑自己的执行偏好。

“保存预览设置”仅保留本次浏览器页面里的选项，不更新真实配置，不改变既有 HTTP 示例连接的协议，不安装或运行 Agent，不保存或上传凭据。Tools 仍使用原有模拟调用流程。新视图是执行设置的设计评审，并非真实协议集成。

## 参数校验：最新确定规则

- 新建草稿的非必填字段全部默认勾选“跳过”，包括 Schema 有默认值的字段。
- 取消跳过按 Schema 默认值或类型初始化，但不立即显示错误。
- 点击、聚焦、离开输入框而未修改，不显示错误。
- 实际修改后按字段校验；点击执行时完整校验，阻止非法请求。
- 跳过删除键；空字符串、null、0、false、空数组和空对象分别按 Schema 判断，不混为“未输入”。
- 历史恢复、已保存请求载入和复制 Tab 保留显式参数，不重新应用新草稿默认跳过。

## 组件设计

`ExecutionRouteSelector`：传输、执行通道及兼容性约束。

`LocalAgentStatus`：设备状态、配对说明与恢复入口。

`StdioCommandFields`：命令与参数分别输入、本机目录、错误状态。

`CredentialStorageSettings`：存储位置与备份范围，独立于工作台登录身份。

`RecordingPolicySummary`：平台历史的记录内容和失败处理说明。

原型集中在 `workbench-execution.js` / `workbench-execution.css`；正式受控组件的划分见 `COMPONENTS.md`，字符串模板不直接转成生产实现。
