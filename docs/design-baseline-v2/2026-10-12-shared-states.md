# 原型统一状态与恢复交互

本轮仅更新 `docs/redesign/` 交互原型。未接入真实 API、权限、发送邀请、MCP 调用或记录上传；未改正式实现。

## 统一表达

| 状态 | 表达 | 下一步 |
| --- | --- | --- |
| 暂无数据 | 说明缺少什么及内容如何产生 | 创建项目、添加服务/变量、邀请成员或前往调试 |
| 筛选无结果 | 明确是筛选未命中，不暗示数据已删除 | 清除筛选，保留项目、服务与环境 |
| 加载中 | 保留工作台上下文，展示列表骨架与读取说明 | 取消加载，或离开页面 |
| 加载失败 | 说明平台不可用或网络中断，保留已有草稿 | 重新加载 |
| 权限不足 | 隐藏被阻断的内容，说明成员身份和角色要求 | 切换项目、查看角色说明 |
| 内容不可用 | 说明可能移除或项目不匹配 | 返回对应列表；保存详情返回已保存记录列表 |
| 只读角色 | 保留可读内容，持续显示操作范围 | 受限操作禁用，说明联系项目管理员 |

结果区的“未执行”、连接/授权错误、变量缺失、邀请过期、记录上传失败继续沿用各模块已有专项交互，不用页面加载错误替代这些业务状态。重试加载不会重新执行工具，也不会重发邀请或重复上传记录。

## 评审入口

各页面上方新增“状态演示”，可选择正常、暂无数据、加载中、加载失败、权限不足、内容不可用。演示条明确说明只模拟本页，不更改项目数据。

加载状态由评审者选择“模拟加载成功”或“模拟加载失败”，用于稳定评审，不用定时器伪造真实网络结果。取消返回加载前的状态；成功/退出回到原页面及保留的草稿、筛选。正式产品异步加载仍应遵循 300ms 后再显示反馈的规范，这个状态演示入口不进入正式产品。

`uiState` 是可分享的原型场景标记，不包含凭据。状态按项目、页面、连接、环境、配置分区、工具页签、记录与团队视图隔离，不改变真实示例角色；权限演示不代表授权实现。

## 实际空态修正

- 调用历史和已保存记录：无源记录时给出调试入口；有记录但筛选未命中时给出清除筛选。
- 工具目录：无搜索结果时提供清除筛选，恢复目录不更改打开的工具。
- 环境变量：区分作用域无定义与筛选无结果；分别添加变量或清除筛选。
- 历史详情失效：使用统一的不可用提示，保留对应列表返回入口。
- 查看者：新增全局只读提示，保留现有模块的操作禁用规则。

## 组件与视觉

`workbench-states.js`、`workbench-states.css` 和 `state-locales.js` 提供原型级共享状态面板、骨架、提示条和双语文案。沿用现有 tokens、Phosphor 图标、页面标题和按钮，不引入独立设计系统。状态内容在页面内呈现，未新增弹窗。
