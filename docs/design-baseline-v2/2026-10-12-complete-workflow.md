# 原型完整流程串联与一致性复核

日期：2026-10-12。仅修改 `docs/redesign` 可交互设计原型。没有正式前后端开发、真实 MCP 调用、账号操作、邮件或平台上传。业务数据仍只存在于本次页面会话，刷新恢复初始示例。

入口：[项目管理](./workbench-preview.html?page=projects&project=commerce)。创建一个新项目自动进入七步项目流程；已有项目也可点击“项目流程”进入。

## 完整路径

**创建项目 → 邀请并接受 → 保存服务配置 → 补齐环境变量 → 连接与工具调试 → 查看同一次调用历史 → 保存请求响应快照。**

项目流程概览展示每步真实示例状态、前置条件和入口。进行中的页面顶部增加简洁的“项目流程 / 进度 / 下一步”导航，不改变既有服务、环境、工具分栏和记录详情的布局。未启用流程的项目保留原来的工作台。

邀请可稍后完成。服务没有任何变量引用时可显式选择“此服务无需环境变量”；这一选择绑定当前服务 ID，不能自动用于其他服务。增加变量引用后重新检查。计数包含显式跳过的可选步骤，概览仍显示“可稍后完成”，不会伪造成员加入或变量创建。

## 本轮修复与统一

| 原断点 | 调整 |
| --- | --- |
| 新建首个服务只有配置页选中，调试会话未选中 | 同步初始服务 ID 与会话环境；环境页、连接、工具和历史使用同一连接 |
| 新服务继承演示请求头及令牌变量名 | 新建请求头为空，授权变量引用使用通用名称；不会凭空要求旧项目的变量 |
| 无服务时顶部出现空下拉框 | 显示“尚未选择服务”并禁用选择；不能创建绑定空 ID 的调试 Tab |
| 服务与环境页面之间缺少连续引导 | 保存服务后进入当前服务的引用校验；补齐变量后下一步回到原服务连接 |
| 下一步重复进入保存页会重建编辑草稿 | 当前来源未变时保留已输入名称、备注与范围 |
| 返回调试可能选中该服务第一个旧 Tab | 保留当前服务上已经选中的草稿，包含恢复创建的新 Tab |
| 文档检索参数沿用商品检索说明 | 使用适用于两类检索工具的参数描述 |
| 流程完成容易只依赖点击 | 从配置保存、环境校验、成员关系、调用快照、历史查看和记录上传状态计算进度 |

新增概览、上下文导航、按钮、标签、表格、表单和错误反馈继续复用既有 tokens、Phosphor 图标、i18next 和页面容器。工作区滚动留在各自内容区域，不使用新弹窗或第二套组件风格。

## 上下文与状态契约

- 项目创建不复制其他项目的服务、变量、历史、保存记录和授权。
- 首个服务成为当前会话服务。进入环境时使用该服务已保存环境，修复表单带入项目、服务及环境；查看其他环境不会自动应用。
- 保存配置不自动连接；缺失引用阻止连接。HTTP 浏览器直连与 Agent/stdio 仍遵守既有通道和授权状态模型。
- 只有连接成功才从流程进入可执行的工具工作区。工具目录始终是原型示例，不是服务发现结果。
- 历史与保存步骤关联当前服务的最新一次已结束调用，包含错误或取消；不会悄悄改用更早的成功调用。
- 查看其他调用不计为本次历史已查看；无关的已保存请求不能完成本次保存步骤。
- 保存步骤只有对应快照上传成功才完成；等待或失败保留当前进度，通过原详情重试同一记录。
- 恢复创建未执行草稿，不带入旧响应，不自动再调用；已有草稿和快照保持独立。
- 已有项目数据、工具内历史范围及语言 / 主题切换行为保持。页面业务状态刷新后重置。

## 浏览器评审路线

1. 从项目管理创建“流程评审项目”，进入 1/7 项目流程。
2. 进入邀请步骤，创建示例邮箱邀请，打开接受流程并模拟接受；回概览应为 2/7。
3. 新增 HTTP 服务，选择浏览器直连，填写 `http://localhost:3000/mcp`。添加请求头 `X-Tenant-ID` → `{{TENANT_ID}}`，保存为 3/7。本地址只作为配置文本，不发请求。
4. 连接会因缺失变量被阻止；下一步进入环境引用检查。补齐 `TENANT_ID` 为 `review-tenant`，保存后 4/7。
5. 下一步回到原服务，模拟连接成功后打开工具。填入检索参数并执行，完成后 5/7。
6. 下一步打开该次调用详情，核对参数和响应，进度 6/7。
7. 下一步保存请求响应快照。选择“上传失败”时仍为 6/7；模拟平台恢复并重试后变为 7/7。
8. 从保存详情恢复到新的调试页，检查参数存在、结果为未执行；工具内历史仍只包含对应连接与工具的调用。

可另行体验“稍后邀请”和“无需环境变量”，以及既有错误响应、取消、授权和 Agent 场景。流程概览不替代各页面的完整状态预览。
