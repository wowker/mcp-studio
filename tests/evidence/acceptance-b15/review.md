## Minor（记录不阻断）

| # | 观察 | 说明 |
|---|---|---|
| M1 | `jsonnumber.String` 对 denormal（如 `1e-323`）的具体尾部数字依赖 `strconv.FormatFloat` 实现 | 测试只断言阈值切换（`<1e-6` 走指数）与符号，不断言 denormal 精确位数。若 Go 版本改变 FormatFloat 最短表示算法，测试不会误红，但同时也不会捕获。可接受：跨 Go 版本的浮点最短表示是语言保证之外的细节。 |
| M2 | 两个 wire 合同测试只覆盖实际被使用的结构子集 | `platform.gen.go` 有 40+ 类型，本次锁 6 个（Health / Bootstrap / Error / Project / Session / Invitation）；`agent.gen.go` 锁 5 个。未被锁的类型若发生 tag 漂移不会被捕获。选择依据：这 11 个是浏览器与 Agent 双方都消费的结构，其余为请求侧或低耦合类型。 |
| M3 | wire 测试是「字段名存在性」断言，不是「字段语义」断言 | 例如 `Project.canRead` 存在即通过，不校验它是否由正确的权限逻辑赋值。权限语义由 B11 platform 深潜与 B13/B14 前端测试覆盖，此处只防生成器漂移。 |
| M4 | `jsonnumber` 的 exponent 位数检查（`len(exponent) > 3`）与数值范围检查（`|n| > 324`）是两条独立闸 | `1e1234` 走位数闸，`1e325` 走范围闸，两者都有测试。但 `1e0325`（前导零裁剪后仍是 3 位、数值 325）走范围闸——未单独断言，已在 `1e0003→1000` 间接证明裁剪路径可用。 |
